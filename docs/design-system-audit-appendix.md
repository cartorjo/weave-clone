### Counting rules
- Comments are blanked before scanning (CSS `/* */`, JS `//` and `/* */`, HTML `<!-- -->`). Literals in comments are listed separately in section I, not counted.
- CSS: every declaration value and every `@media`/`@container` prelude. Selectors are not scanned.
- Definitions: in styles/main.css, lines 63-177 (`@theme`), 179-249 (`:root`) and 251 (`@media` `:root` override) are token definitions. Any `--*` declaration in another file is a "token definition outside the token file". Neither counts as a raw value.
- `var(--x)` and `theme(--x)` are token consumption and are skipped. A `var()` fallback is scanned and counted.
- Kinds: **color** = hex, `rgb()/rgba()/hsl()/hsla()`, named colors including `transparent`, and `color-mix()` ratios. **length** = px, rem, em, ch, vw, vh, dvh, % and fr. **time** = ms and s. **other** = unitless design numbers: font-weight, line-height, z-index, aspect-ratio, opacity, `scale()`/`grayscale()` factors, stroke-width/miterlimit, hyphenation limits, angles (deg), easing numbers. **arbitrary** = Tailwind `[...]` values, arbitrary properties and variants, and `(--var)` shorthands.
- Excluded: bare `0`, `currentColor`, `inherit`, `none`, structural integers (grid lines and spans, `repeat()` counts, `calc()` operands, `flex: 1`), the scale endpoints `scaleX(0)`/`scaleX(1)`, the RTL flip `scale: -1 1`, font-family names, `url()` paths, and `@font-face` descriptors (25 declarations in styles/00-fonts.css:4-8, which describe the font files).
- Notes: "value = --x" means the literal equals an existing main.css token value (rem and px compared at 16 px). This is value equality, not a claim that the token is semantically right. "structural fill" (100% width/height), "equal track" (`1fr`) and "structural centring/circle" (50%) mark literals that probably stay literal. They are counted, and shown separately as "structural".
