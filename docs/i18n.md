# English version (i18n)

German is the source language. The American English twin of every page lives
under `/en/` (owner decision 2026-09-27: host `emposo.de`, English slugs,
Hays' official English legal texts, German launches first). **English is
published** (owner decision 2026-09-27). `npm run build` builds both languages,
and the DE|EN switch and hreflang pairs are on every page.

**Temporary:** `/en/privacy-policy/` shows the German privacy notice (marked
`lang="de"`) until Hays' official English text is supplied. Replace
`pages/en/datenschutzerklaerung.html` with it, verbatim, in the same frame as
`pages/en/nutzungsbestimmungen.html`.

## How a page becomes English

| Kind of copy | German source | English source |
|---|---|---|
| Page and section bodies | `pages/x.html`, `sections/x.html` | `pages/en/x.html`, `sections/en/x.html`, same markup |
| Header, footer, contact form | `{{t:key}}` in `partials/` | `STRINGS.en` in `content/i18n.mjs` |
| Shared components | `t('key')` in `content/render.mjs` | `STRINGS.en` |
| Cases, disciplines, industries, jobs, management | `content/site-data.mjs`, `render.mjs` profiles | `content/site-data.en.mjs` (text fields by slug) |
| Image alt text | `alt` in `assets/supplied/manifest.json` | `alt_en` |
| Titles and meta descriptions | `pages.mjs` | `META` in `pages.en.mjs` |
| URLs | — | `PATHS` and `CASE_SLUGS` in `content/i18n.mjs` |

English sources keep German internal paths (`/kontakt/`): `assemble.mjs`
rewrites every internal href through the route map, so links cannot drift.

## Build and gates

- `npm run build:en` builds the English twins into `en/` (git-ignored until
  publication) and writes every German fallback to `.i18n/untranslated.json`.
  That file is the translation catalogue: `ui:`, `data:`, `meta:`, `alt:` and
  `file:` entries.
- `npm run check:i18n` (part of `npm run check`) checks:
  - every page has its twin;
  - `lang` and the canonical;
  - reciprocal hreflang (de, en, x-default = de);
  - no German links on English pages;
  - identical tag skeletons between twins: only text and localized attribute
    values may differ.
- `node tools/check-i18n.mjs --complete` also fails on any remaining
  fallback. English is published only when it passes.

## Publishing English

1. Every string is approved by the owner (the copy rule); the legal pages are
   Hays' official texts, verbatim.
2. `check:i18n --complete` passes.
3. Add `'en'` to `PUBLISHED` in `content/i18n.mjs`. The German pages then gain
   their hreflang links and the sitemap lists both languages.
4. Remove `/en/` from `.gitignore` and run `npm run copy:accept` (the
   baseline diff is the owner's review surface).
5. Switch the old `/en/*` redirects in `serve.json` to the English successors.
