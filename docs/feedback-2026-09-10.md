The site now contains 42 generated documents: 41 content pages and the 404 page.
The implementation updates the homepage, navigation, services, industries,
reference projects, company profile, management, career entry points and footer.

over earlier proposals and hidden worksheets. In particular, the revised

## Reference projects and industry structure

`content/site-data.mjs` holds the eight disciplines, five industries and all ten
projects. Shared renderers produce the homepage references, complete project
indexes, industry references, service-page examples and project detail pages.
Project challenges and solutions are brief editorial paraphrases of the
provided project summaries; no additional client names or technical results
were introduced.

Automotive belongs to Industrials & Manufacturing and remains available as a
more specific project filter. The datacenter move is assigned to Automotive,
as specified in the workbook. Aerospace and Technology have no supplied
reference cases; their industry pages link to relevant expertise and contact,
and the filter shows an explicit empty state rather than misclassifying a case.

The project data preserves “over 70%” for MLOps and “up to EUR 80,000 per month”
for the knowledge assistant. The unsupported 100% figure for homologation was
replaced with the supplied result: deadlines met and complete, auditable
documentation. All ten projects have their own URLs and related expertise links.

The more precise company worksheet wording is used for quality claims: ISO 9001
certification and a completed TISAX assessment with scope/evidence available on
request. Project standards, methods and regulatory requirements are described
separately; no certification logos were invented.

## Assets and implementation

Eighteen selected photographs from all five supplied asset categories were
imported as responsive AVIF/WebP images with JPEG fallbacks, EXIF orientation
applied and metadata removed by the image pipeline. Their 90 image derivatives
plus source manifest total approximately 7.1 MB. The 1600px hero AVIF is about
86 KB. Portrait resolution is bounded by its source dimensions.

`assets/supplied/manifest.json` maps each image back to its original filename and
records alt text, output dimensions and byte sizes. Raw downloads are not copied
into the site. Ordinary builds do not depend on the Downloads folder; the import
script accepts an optional source directory when assets need to be regenerated.

Roboto and its OFL license are stored locally. Page loads make no Google Fonts
requests. Existing routes remain available, with the shared navigation pointing
to the revised content. Homepage ordering is explicit in `pages.mjs`. The
superseded section templates (`02a-journeys`, `07-slider`, `07a-quote`,
`07ab-career`), the pre-manifest `pages/case-study-data2ai-platform.html`,
`js/03-connection-system.js`, the unwired `tools/build-images.mjs`, the unused
Inter font files and their dead component CSS were removed in the second pass;
git history preserves them.

## Second pass (completion sweep, same feedback round)

A follow-up gap audit against the PDF annotations and workbook closed the
remaining items:

- **Color rule finished.** The last three pre-feedback navy gradient stops
  (`rgba(0,13,41,…)`) became midnight blue, every washed `rgba(10,5,50,.58–.78)`
  text color on light surfaces was lifted to full ink, and the three remaining
  orange text labels on light surfaces (`about-facts`, `about-principles`,
  `portfolio-model`) now use ink text with an orange rule accent, matching the
  homepage stats treatment.
- **Hover states completed.** The stats row got the annotated hover (number
  bold + orange, label bold, numbers slightly larger; mirrored on the about
  facts). Navigation links and the current-page marker now show an orange
  underline instead of the previous no-op color swap; the header CTA no longer
  inverts to navy/white on hover; the footer "Projekt besprechen" arrow is
  orange per the "arrows orange on blue" comment.
- **Stats icons and count-up.** The homepage stats carry provisional outline
  icons in the draft's motifs (building, people, documents, pin) until the
  promised icon folder arrives, plus a one-shot count-up (`js/07-countup.js`)
  that is skipped under reduced motion and always ends on the exact authored
  strings.
- **Eight discipline detail pages.** `content/render.mjs` gained a
  `discipline:` generator; seven generated pages join the hand-authored
  AI & Daten page so every discipline is its own portfolio category
  (workbook sheet 03). The expertise overview, both group pages, the sitemap
  and `content/site-data.mjs` hrefs now point at the detail pages.
- **Zertifizierungen page.** `/zertifizierungen/` collects the existing hedged
  certification copy (ISO 9001, TISAX via ENX, standards, methods, Compliant
  Sourcing®), linked from the footer, the sitemap and the portfolio quality
  section — closing the workbook's level-3 sitemap entry.
- **Small fixes found in browser review.** Breadcrumbs on light sections
  render in ink (the Zertifizierungen breadcrumb was white on white), and the
  footer wordmark image now fills its cropping box so the old tagline no
  longer peeks out beneath it.

The footer points to Emposo’s existing [imprint](https://emposo.de/impressum/)
and [privacy notice](https://emposo.de/datenschutzerklaerung/). The workbook’s
linked [existing solutions overview](https://emposo.de/solutions/) was reviewed;
the visible workbook’s eight-discipline structure governs the new service
overview. Company is optional in the contact form so career enquiries can use
it. The form clearly explains that it prepares an email in the visitor’s own
email program. Existing preview `noindex` settings remain in place.

## Verification

`npm run check` builds the site and checks all 34 generated documents for local
links, anchors, responsive images, unresolved templates, duplicate IDs, one H1
per page and superseded branding/arrows. `git diff --check` checks patch hygiene.

Chrome checks cover all 33 content pages at 1440px and 390px. They inspect
horizontal overflow, clipped text, image decoding, JavaScript/HTTP errors and
automated WCAG A/AA checks through axe. Additional review covers the changed
templates and the 404 document at 320px, 768px, 1280px and 1440px. The narrow
review caught and corrected an inherited image aspect-ratio/caption overflow.

Interaction checks cover desktop/mobile menus and Escape, combined project
filters and empty states, industry filter URLs, career enquiry preselection,
reduced motion, and project navigation without JavaScript. Automated checks
are evidence about the tested states, not a claim of complete accessibility
conformance. The recorded results are in
`audit-evidence/feedback-2026-09-10/verification.json`.
